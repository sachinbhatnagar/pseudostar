Problem:
This pseudocode algorithm should ask the user to enter a number between 1 and 10 and should output whether the data entered is correct or not correct

Solution:

<!-- prettier-ignore-start -->
OUTPUT "Enter a number between 1 and 10"
INPUT number
IF number >= 1 AND number <= 10 THEN
    OUTPUT "That is correct"
ELSE
    OUTPUT "That is incorrect"
ENDIF
<!-- prettier-ignore-end -->
